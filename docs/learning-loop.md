# Learning loop

How a topic moves from first lesson to passed to revisited. Early notes; values are still open (see [Evaluation](evaluation.md)).

## The stages

1. **Name a topic.** You say what you want to study. No setup, no workflow to configure.
2. **Calibrated lesson.** ACE writes a short lesson pitched at your level. See [Calibration](calibration.md).
3. **Work problems.** Real problems from textbooks and courses.
4. **Score against a rubric.** Answers are checked and scored; the model grades, fixed rules apply the bar. See [Pass criteria](pass-criteria.md).
5. **Pass or keep working.** The topic counts as done only when the bar is met. Otherwise you keep going.
6. **Scheduled revisit.** Passing sets a revisit date. After the delay you prove it again.

## Division of labor

Proposed, not yet decided: the model owns the content (lessons, grading) and fixed code owns the state (the pass bar, scheduling revisits). Every attempt is recorded as an event, and a topic's state is derived from that record. See [Decisions](decisions.md).
