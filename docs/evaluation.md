# Evaluation

How each design choice will be tested before it is fixed. Early notes; the principle is decided, the tests are not yet run.

## The principle

Specific values (thresholds, targets, intervals) stay open until they have been tested. They depend on real learners, so guessing them now would be wrong more often than right.

## To be set by testing

- The pass bar: how many problems, of what mix, and how strict the explain-back is.
- The target difficulty for practice.
- The revisit target and the scheduling algorithm.
- The length of the diagnostic.

## Open

Single-user first, or accounts from the start, is undecided. See [Decisions](decisions.md).
