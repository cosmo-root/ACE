# ACE — Actually Comprehend Everything

I'm building a study harness. Early days, most of it is still undecided.

## The idea

Studying right is a solved problem. Learn at full depth. Prove it on real
problems. Come back after time passes and prove it again. Everyone knows the
shape. Nobody sticks to it, because running it takes constant discipline.

ACE runs the shape for you. That is the whole product: a study plan with a
memory that schedules the work, checks the bar, and brings topics back on
time. The method is standard. The unique part is a harness that actually holds
you inside it, session after session.

## What it is

A record of understanding per topic, lessons worth reading, practice from
textbooks and courses, a clear bar for passing each topic, and revisits after
a delay. I do the learning. The harness keeps the order and the standard
steady.

The pieces I'm thinking about: a profile of what I know and how I learn best,
full-strength lessons, sourced problems with coaching, pass criteria per
topic, and spaced retests. Each piece is still TBD.
